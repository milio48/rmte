Remote Terminal Relay & Cloud IDE

Zero-config, real-time, multi-user remote terminal sharing and lightweight Cloud IDE with AES-GCM 256-bit End-to-End Encryption (E2EE), resizable File Explorer, CodeMirror editor, and embedded browser preview in a single binary.

Key Features

Engineered for security, ease of use, and maximum performance.

🌐
Embedded Browser Preview
Test local web servers (Vite, Next.js, Go, Python) directly inside the Web IDE tab bar. Built-in relay-assisted reverse proxy over a single port with HMR WebSocket hijacking and zero DNS requirement.
🔒
End-to-End Encryption
All terminal frames, file operations, and control messages are secured with AES-GCM 256-bit E2EE. The relay server is a zero-knowledge dumb pipe that never sees plaintext data or passwords.
🪟
Windows Native ConPTY
Full pseudoterminal support on Windows 10/11 using ConPTY: command history with arrow keys (↑ / ↓), caret navigation (← / →), tab completion, and native ANSI styling.
📁
Split-Workspace Cloud IDE
Complete workspace equipped with a resizable absolute-path File Explorer, drag-and-drop upload/download, CodeMirror text editor, and multi-tab interactive terminal shells.
⚡
Background Daemon Mode
Run sessions detached in the background with -q or --quiet for both serve and share. Prints connection info and PID, and cleanly terminates with rmte stop.
📦
Single Self-Contained Binary
Zero runtime dependencies. Web assets are embedded directly into the Go binary. No Node.js, npm, or external web server required.

Command Cheat Sheet

Quick reference for running RMTE commands:

1. Standalone Session

rmte serve --web-preview

Launches relay + host in one process on port 8048 with browser preview enabled.

2. Run in Background

rmte serve --web-preview -q

Runs detached in background, prints shareable link + PID, then returns to prompt.

3. Stop Background Session

rmte stop <session_id | pid>

Cleanly terminates the background session and cleans up PID files.

4. Share to External Relay

rmte share --server-relay="..." -q

Connects outbound to a central relay without opening any inbound ports.
