🚀 Common Command Workflows

Real-world command recipes from the official RMTE documentation:

🚀 Instant Public Share

Public Relay
COMMAND
./rmte -q

Instantly connects outbound to my.rmte.biz.id with Web Browser Preview enabled. Runs detached in the background and prints connection URL with PID.

🔑 Public Custom Session

Public Relay
COMMAND
./rmte --id="mysession" --pass="supersecret" -q

Shares terminal to public relay using your preferred Session ID and E2EE password. Web preview and file management are active by default.

💻 Quick Local Session

Standalone
COMMAND
./rmte serve --web-preview

Launches relay + host on 127.0.0.1:8048 with embedded Web Browser Preview enabled. Generates a random password and prints a local browser link.

🖥️ Single VPS Server (Case 1)

Self-Hosted
COMMAND
./rmte serve --public --hostname="rmte.example.com" --pass="secret123"

Self-contained server hosting both the WebSocket relay and terminal host on port 8048. External host connections (share) are strictly rejected.

🌐 Dedicated Relay Hub (Case 2)

Relay Only
COMMAND
./rmte serve --mode=relay --public --hostname="relay.example.com"

Dedicated central router running in multi-host mesh. Only opens port 8048 for HTTP Web UI and WebSocket routing, without spawning a local terminal shell.

🔄 Hybrid Relay & Host

Hybrid
COMMAND
./rmte serve --mode=hybrid --public --hostname="relay.example.com"

Runs a local host session on the server while simultaneously serving as a public relay hub accepting external connections from rmte share.

📤 Outbound Host (Share)

Outbound
COMMAND
./rmte share --server-relay="ws://relay.example.com:8048/ws-rmte" --pass="secret123" -q

Connects outbound to a private relay. Requires zero open inbound ports on the host machine, functioning effortlessly behind strict NAT and firewalls.

👥 Client Join (TUI)

Client
COMMAND
./rmte join --id="mysession" --pass="secret123"

Connects from another terminal prompt into an interactive TUI menu: [j] Join Tab, [n] New Tab, [s] Switch Tab, [c] Chat, and [q] Quit.

🛑 Stop & In-Place Update

Lifecycle
COMMAND
rmte stop <session_id | pid> && rmte update --restart

Cleanly terminates background daemons (rmte stop). Use rmte update --restart to upgrade binary in-place without disconnecting active web viewers.
